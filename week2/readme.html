Week2 Sketch

This generative artwork is inspired by the Bauhaus style, using simple geometric shapes and a red, yellow, blue, and black color palette. Each mouse click randomly changes the shapes’ colors, positions, sizes, and rotations. The background also changes between different shades of light yellow. By using randomness, each click creates a new composition while keeping the same visual system. The project explores how a simple set of rules can create many different results.
